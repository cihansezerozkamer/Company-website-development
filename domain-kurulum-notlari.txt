@, başında www bulunmayan ana domaini ifade eder: istkesintisizgüç.com.
A kaydı, bir ismi IPv4 adresine bağlar. Yukarıdaki dört IP, GitHub Pages'in
özel domainler için resmi olarak yayımladığı adreslerdir. Dört kaydı,
GitHub'un tarif ettiği adres kümesinin tamamını kullanmak için ekledik.
Hepsi aynı siteye hizmet veren GitHub Pages altyapısına yönelir.
Bunlar dört ayrı web sitesi veya dört ayrı hosting satın alımı değildir.

CNAME kaydı, www.istkesintisizgüç.com adını GitHub hesabının Pages adresine
bağlayan bir takma addır. Hedefin sonunda /Company-website-development/
yazılmaz; DNS kaydı yalnızca alan adı içerir. Hangi deponun gösterileceğini
GitHub Pages'te kaydettiğimiz özel domain ayarı belirler.

TTL 30 dakika, DNS cevaplarının önbellekte tutulma süresidir.
Tüm dünyada değişikliğin tam olarak 30 dakikada yayılacağı garantisi değildir.

YAPILAN İŞLEMLER

1. Açık Spaceship hesabında satın alınan domain kontrol edildi.
2. Sitenin GitHub Pages üzerinden, main dalının kök klasöründen
   yayınlandığı doğrulandı.
3. Deponun Settings > Pages > Custom domain alanına
   xn--istkesintisizg-tjb94a.com yazılıp kaydedildi.
4. GitHub, deponun kökünde CNAME dosyasını oluşturdu.
   Bu dosyanın içeriği: xn--istkesintisizg-tjb94a.com
5. Spaceship Advanced DNS ekranında yukarıdaki dört A kaydı ve
   www için bir CNAME kaydı eklendi. Nameserver'lar Spaceship'te kaldı:
   launch1.spaceship.net ve launch2.spaceship.net.
6. Spaceship çoklu A kaydı uyarısı gösterdi. Otomatik onay denetimi
   işlemi durdurunca kullanıcıdan somut onay istendi. Kullanıcı
   "onaylıyorum" dedikten sonra kalan farklı GitHub IP kayıtları kaydedildi.
7. GitHub'un oluşturduğu CNAME commit'i yerel depoya alındı.
8. Ana domainin tarayıcıda siteyi açtığı doğrulandı.
9. Ana domainin HTTPS sertifikası kullanılabilir duruma geldiğinde
   Enforce HTTPS seçeneği açıldı. HTTPS bağlantısı tarayıcıda doğrulandı.
10. Önceki yazım düzeltmeleri commit edilip GitHub'a gönderildi.
    GitHub Pages yayını başarıyla tamamlandı. Yeni domain üzerinde
    "Sürpriz kesintiler işinizi durdurmasın." ve "Ana Sayfa" yazımları
    kontrol edildi.
